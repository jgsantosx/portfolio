## Sobre o projeto

Este projeto foi desenvolvido como meu portfólio profissional, reunindo informações sobre minha trajetória, experiência, formação acadêmica, habilidades técnicas e projetos.

O frontend possui uma identidade visual dark, com foco em uma interface moderna, responsiva e objetiva.

### Principais seções

- Início
- Sobre mim
- Experiência profissional
- Formação acadêmica
- Projetos
- Habilidades
- Contato
